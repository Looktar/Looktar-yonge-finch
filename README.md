# 央街·芬治 黄昏 · Yonge × Finch Dusk

浏览器 3D 第一人称打僵尸，地图按 1:1 还原多伦多北约克 Yonge St × Finch Ave 路口。

```
npm ci
npm run build   # → dist/index.html（单文件）
npm run serve   # http://localhost:8765/
```
