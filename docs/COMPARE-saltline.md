# 和 Saltline 的深入对比（v0.6.2，2026-11-25）

对比图：`docs/screenshots/saltline-vs-v0.6.2.jpg`（左 Saltline，右本游戏；第一行和第三行用的是同一张 Saltline 截图，分别对照我们的逆光走廊和出生点）。

## 逐项打分（10 分制，Saltline 约 9）

| 方面 | 分 | 证据（截图里看得到的） | 差距的根源 |
|---|---|---|---|
| 枪的模型 | 6 | 零件数接近（162 件对“几百件”），导轨、瞄具、护木都在 | 我们的枪表面只有一种冷灰黑色；Saltline 的枪有雨珠高光、边缘磨亮、塑料和金属反差，**明暗对比强得多** |
| 枪的构图 | 6.5 | 已按 Saltline 实测校准，枪口停在准心右下 | 我们的枪离镜头近、瞄具占画面大；Saltline 的枪更长更细，从右下角斜伸到画面中央 |
| 手和手臂 | 4 | 放样手套、手臂、换弹时手会动 | 手臂是一根光滑管子，没有布料褶皱、没有护具；Saltline 的手臂几乎全藏在枪后面，我们露得多反而暴露粗糙 |
| 换弹动作 | 5 | 有关键帧、弹匣跟手、音效节点 | 没有拍过真人参考，节奏偏机械；手指不会动（手是一整块） |
| 光照 | 5 | 逆光雾和光束都有 | **这是最大的单项差距**。Saltline 有真正的体积光（读阴影图的光线步进），近处物体在逆光里压成剪影、地面高光沿视线拉长；我们的逆光是一片均匀的米色雾，近处物体发灰，没有剪影 |
| 湿地面 | 5 | 水坑倒影、拉丝反光 | Saltline 整个地面都在反光、有雨在下；我们大部分地面是哑光的，只有零星水坑 |
| 近景道具密度 | 4 | 隔离墩、锥桶、消防栓、加油站 | Saltline 视野里每平方米都有东西（管线、电箱、栏杆、链条、标识）；我们的人行道和路面大片是空的 |
| 中景建筑 | 3.5 | 塔楼有阳台、壁柱、亮窗 | **第二大差距**。集装箱每块都有波纹、锈迹、标签贴花；我们的塔楼是带重复窗格贴图的方盒，近看像纸板 |
| 材质细节 | 4.5 | 枪、道具有程序磨损 | 楼、路面、人行道的污渍、雨痕、接缝密度远低于 Saltline |
| 车 | 4 | 轮廓已对 | 车灯是白块、没有格栅和门把手，车漆没有反射环境 |
| 僵尸 | 4 | 统一成感染士兵 | 只有一个模型和三个动作，没有受击变形或肢体残缺 |
| **总体** | **约 5** | | |

## 差距排序（按“改了以后画面提升 / 工作量”）

1. **体积光和逆光剪影**：在后处理里加读阴影图的光线步进（Saltline 用 10–40 步），把均匀雾换成有光束、有阴影的体积雾。影响每一个面向太阳的画面。
2. **地面全面湿润**：把“零星水坑”改成“整片湿沥青 + 少量积水”，配合实时下雨粒子（9000 个实例面片，几乎不费 CPU）。
3. **枪的材质对比**：金属部分更暗、边缘磨亮更明显，聚合物更哑，雨珠更多。
4. **近景杂物**：沿人行道随机撒电箱、管线、链条栏杆、施工围挡、标识牌（零件库已具备）。
5. **路口四角的楼逐栋精做**：窗框、阳台板、雨棚、空调外机、楼体污渍。
6. **手臂褶皱和手指动画**，换弹节奏按真人视频重新打关键帧。

前两项是大头：Saltline 的“质感”大半来自光和湿，而不是模型本身。
